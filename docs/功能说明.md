## 2. 用户视角功能

### 2.1 认证
- 登录获取 JWT（`POST /api/v1/auth/login`），登录行为记录 IP/设备/时间，可在「我的登录日志」自查。
- 修改个人资料与密码（`PUT /auth/profile`，`POST /auth/profile/change-password`）。

### 2.2 问答与引用
- 自然语言提问，SSE 流式返回；支持停止生成与重新生成。
- 每段带 `[n]` 来源编号，点击定位到来源卡片；点击卡片在知识库浏览器中跳到对应章节（`/documents-browser?doc=..&section=..`）。
- 通过「事实一致性校验」徽标提示回答与来源的一致性状态；不确定内容会拒答。
- 支持按文档版本筛选检索范围。

### 2.3 会话管理
- 新建、历史列表、双击重命名、删除。
- 导出为 Markdown / 纯文本（`GET /conversations/{id}/export`）。
- 生成只读分享链接（可设有效期 TTL；`POST /conversations/{id}/export/share`），匿名可访问（`GET /share`）。

### 2.4 反馈
- 对每条回答点赞/点踩并可附改进意见（`POST /feedback`）。仅 member 及以上可提交。

### 2.5 知识库浏览
- `/documents-browser` 列表查阅已导入文档全文，支持按章节锚点定位。

> 权限级别：`member` 具备读+反馈+分享等写操作；`viewer` 仅读（不可反馈）。

## 3. 管理员视角功能

### 3.1 用户与权限
- 用户增删改查、启用/禁用、重置密码；角色 assign。
- 租户列表；用户组增删、组成员管理（`/auth/groups*`）。
- 分类授权矩阵：按 用户组→分类 配置文档可读/可管范围（`/categories/grants*`）。

### 3.2 知识库管理
- 拖拽/选择文件上传（PDF/Word/TXT/MD，≤20MB），自动解析·切片·向量化，后台任务进度可见。
- 目录扫描 `/scan`（支持 background 异步）、网页导入 `/web-import`。
- 文档列表搜索/状态筛选/分页；批量设分类、设可见权限（本租户/仅管理员）、批量删除。
- 单篇文档详情、编辑展示名/版本号、覆盖上传（新版本）、失败重试。
- 修订历史与回滚（`/documents/{id}/versions*`）。

### 3.3 可观测与监控
- 全量对话统计（拒答率、反馈、链路）（`/conversations/admin/stats`）。
- 链路耗时（`/traces*`、`/traces/{id}/detail`）、接口性能 P99/QPS（`/metrics/endpoints`）、LLM Token 用量（`/metrics/usage`）、慢请求（`/admin/slow-requests`）。
- 资源水位曲线（`/admin/resource/*`）、操作审计日志（`/audit`）、评估摘要（`/eval/summary`）。

### 3.4 运行时运维
- 提示词热更新：`/admin/prompt`（GET/PUT），保存即生效，支持恢复默认。
- 模型切换：`/admin/models/llm`、`/admin/models/embedding` 运行时切换并复用配置。
- 检索参数：`/admin/retrieval` 运行时调整 top_k、相似度阈值、混合检索权重等。

### 3.5 工单与通知
- 工单生命周期（pending→processing→resolved→closed，超时 reopen）、催办规则。
- 用户通知（SQLite 落库、保留期自动清理）。

## 4. 关键业务规则

| 规则 | 说明 |
|---|---|
| 防幻觉 | 低相关片段丢弃；关键词覆盖率下限；回答与来源一致性校验；不确定即拒答 |
| 增量导入 | 按文档指纹（名称+大小+mtime）跳过未变化文档 |
| 版本管理 | 覆盖更新生成新修订；回滚产生新修订 |
| 多租户隔离 | 知识、会话、版本均按 tenant_id 隔离 |
| 分类可见性 | 非管理员仅可见本租户 `access_scope!=private` 且分类∈授权范围（或未分类）的文档 |
