# 通知中心与工单系统

延续「内部工具、管理员统一管控」的设计原则，内置两套轻量协同能力：**通知中心**（用户侧被动接收事件）与**工单系统**（用户↔管理员问题流转）。

两者均基于 SQLite 轻量落地（零迁移）、随事件自动触发、按租户隔离，任何账号不手动操作即可保持消息闭环。

## 1. 通知中心

### 1.1 触发场景与接收人

| 通知类型 | 触发场景 | 接收人 | 示例内容 |
| --- | --- | --- | --- |
| `ticket_status` | 工单状态变更（待处理→处理中→已解决→已关闭） | 工单提交人 | 您提交的工单 TK001 已由管理员标记为【已解决】，请确认。 |
| `ticket_reply` | 管理员新增回复 | 工单提交人 | 管理员回复了您的工单 TK002，请查看。 |
| `kb_update` | 管理员上传 / 更新 / 重建索引 | 全租户（或指定用户组） | 知识库已更新：新增《K3s 高可用部署指南》，共 45 个切片。 |
| `announce` | 管理员手动广播系统维护公告 | 全租户（或指定用户组） | 系统将于 2026-08-25 02:00-04:00 维护…… |
| `permission` | 管理员调整用户所属组或分类授权 | 被调整的成员 | 您的知识库访问权限已更新，新增分类【安全加固手册】的读取权限。 |

### 1.2 触发实现

- 在对应后端事件成功后调用通知存储写库（见 `docs/architecture.md` 第 7 章），无需前端参与。
- 通知「自动触发、非侵入」，仅在主页右上角 🔔 显示红点与未读数，不打断操作。
- 工单**催办不推送给管理员**：管理员侧仅在工单列表显示「⚠️ 已催办」标记，辅助优先处理。

### 1.3 功能清单

| 功能 | 说明 | 优先级 |
| --- | --- | --- |
| 通知入口图标 | 右上角 🔔，未读时红点（含数量） | P0 |
| 下拉列表 | 最近 5 条，标题/时间/已读未读状态 | P0 |
| 分类切换 | 全部 / 工单动态 / 系统公告 / 知识库更新 | P1 |
| 标记已读 | 单条标记已读 / 全部已读按钮 | P0 |
| 详情跳转 | 工单类→工单详情；知识库→浏览器/文档详情 | P0 |
| 独立页面 | 下拉底部「查看全部通知」进入分页列表 | P0 |
| 通知删除 | 单条删除 / 批量删除 | P1 |
| 保留策略 | 默认 90 天自动清理（`RAG_NOTIFY_RETENTION_DAYS` 可配置） | P2 |

## 2. 工单系统

### 2.1 状态机

```
pending(待处理) → processing(处理中) → resolved(已解决) → closed(已关闭)
      ↑______________________ 7 日内 reopen(重新打开) ______________│
```

- **用户端**：提交 → 跟踪 → 催办 → 确认关闭 →（7 日内）重新打开。
- **管理端**：总览 → 详情回复 → 状态流转（可附处理说明）→ 统计。

### 2.2 用户端功能

| 功能 | 说明 | 优先级 |
| --- | --- | --- |
| 提交入口 | 个人中心右上角头像菜单「＋ 提交工单」及独立页 `/tickets.html` | P0 |
| 工单表单 | 类型（必选）/ 标题（≤50 字）/ 描述（≤1000 字）/ 紧急度（普通/紧急）/ 附件（≤10MB） | P0 |
| 提交反馈 | 返回工单编号（`TK20260819001`）与「已提交，管理员将在 1-2 个工作日内处理」 | P0 |
| 我的工单列表 | 编号/类型/标题/状态/提交时间/最后更新 | P0 |
| 工单详情 | 基本信息 + 描述附件 + 管理员回复时间线；已解决后显示「确认关闭」 | P0 |
| 催办 | 待处理或处理中、且满 3 个工作日未更新时出现按钮，每单限 2 次 | P1 |
| 确认关闭 | 已解决后用户确认，关闭后不可再回复 | P1 |
| 重新打开 | 已关闭工单 7 天内可重开并补充说明 | P2 |

### 2.3 管理端功能

| 功能 | 说明 | 优先级 |
| --- | --- | --- |
| 工单总览 | 编号/类型/标题/提交人/紧急度/状态/提交时间/催办标记 | P0 |
| 状态筛选 | 待处理 / 处理中 / 已解决 / 已关闭 + 类型 + 紧急度组合 | P0 |
| 详情与回复 | 右侧/底部 Markdown 回复，提交后用户端即时可见（触发通知） | P0 |
| 状态手动流转 | 待处理→处理中→已解决→已关闭，可填处理说明 | P0 |
| 紧急工单 | 红色高亮 + 优先排序 | P1 |
| 催办提醒 | 被催办工单显示「⚠️ 已催办」标记 | P1 |
| 统计仪表盘 | 按类型分布 / 状态分布 / 平均处理时长 / 近期趋势 | P1 |

## 3. 数据落库

| 文件 | 内容 | 说明 |
| --- | --- | --- |
| `data/notify.db` | `notifications` 表，含 `user_id`/`type`/`is_read`/`created_at` | 单条或广播，携带 `tenant_id` 隔离；90 天自动清理 |
| `data/tickets.db` | `tickets` + `ticket_replies` 两张表 | 工单（含状态机/催办计数/处理说明）+ 管理员回复时间线 |

## 4. 相关配置

| 配置项 | 默认 | 说明 |
| --- | --- | --- |
| `RAG_NOTIFY_DB_PATH` | `./data/notify.db` | 通知中心 SQLite 路径 |
| `RAG_NOTIFY_RETENTION_DAYS` | `90` | 通知自动保留天数 |
| `RAG_TICKET_DB_PATH` | `./data/tickets.db` | 工单系统 SQLite 路径 |
