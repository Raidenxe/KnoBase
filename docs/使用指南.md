## 2. 用户操作手册

### 2.1 登录与账号
- 输入用户名/密码登录，Token 存于浏览器 `localStorage`，退出即清除。
- 可在「我的」处修改密码、查看登录日志（IP/设备/时间）。

### 2.2 进行问答
1. 在输入框输入维保问题（例：“SmartOps 默认管理员账号是什么?”），回车或点「发送」。
2. 回答以 Markdown 呈现，`[n]` 为来源编号：
   - 点击 `[n]` → 页内滚动到对应来源卡片；
   - 点击来源卡片 → 新标签打开知识库浏览器定位到该章节。
3. 支持「🔁 重新生成」「■ 停止生成」。

### 2.3 会话与分享
- 「＋ 新建会话」；历史会话在左侧列表，双击重命名，悬停 ✕ 删除。
- 「⬇ 导出」可导出 Markdown 或纯文本。
- 「🔗 分享」生成本会话只读链接（可设有效期），自动复制；对方匿名打开 `…/s/{token}` 查看。

### 2.4 反馈
对每条回答点「👍 有用 / 👎 无用」，可补充意见后提交，帮助优化提示词与检索。

### 2.5 检索范围
「检索范围」下拉可按文档版本（`v..`）过滤，仅检索对应版本，提升针对性。

## 3. 管理员操作手册

### 3.1 账号与权限
1. 控制台 → 「用户管理」：新增用户（指定角色/租户）、编辑、禁用、重置密码、删除。
2. 「用户组」：创建组并维护成员。
3. 「分类授权」：按 用户组→分类 配置文档可读/可管范围（授权矩阵）。

### 3.2 知识库管理
1. 控制台 → 「知识库」：
   - 拖拽或选择文件上传（PDF/Word/TXT/MD，≤20MB），自动解析·切片·向量化，进度见「入库进度」。
   - 搜索/按状态筛选；可批量设分类、设权限（本租户/仅管理员）、批量删除。
2. 单篇文档可查看详情、编辑展示名/版本号、覆盖上传新版本、失败重试。
3. 「分类管理」维护知识分类；删除分类仅将文档移入未分类，不删文档。
4. 修订历史与回滚：`批量` 之外，单篇文档「版本」可查看历史并回滚。

### 3.3 监控与运维
- **全量对话 / 用户反馈 / 链路耗时 / 接口性能 / LLM 用量**：掌握运行状况、拒答率与成本。
- **提示词**：在线编辑 System Prompt（Ctrl+S 保存即生效，可恢复默认）。
- **模型切换**：运行时切换 LLM/Embedding（需有效 API Key；未配置则回退 Mock）。
- **检索参数**：运行时调整 top_k、相似度阈值、混合检索权重等，保存即生效。
- **资源水位 / 慢请求 / 操作日志**：定位性能瓶颈并审计敏感操作。

### 3.4 工单与通知
处理用户工单（状态流转与催办）、管理通知中心触达规则（见《工单与通知》）。

## 4. 运维手册

- 启动：`./start.sh`（可选 `RAG_PORT`/`RAG_HOST` 覆盖）；停止：`./stop.sh`。
- 配置：`.env`（`RAG_*` 全量清单见 [deployment.md](deployment.md)），改后需重启生效（运行时配置除外）。
- 知识库导入：
  ```bash
  python -m scripts.ingest <目录>            # 增量
  curl -X POST :8000/api/v1/documents/scan -d '{}'   # 后台异步
  ```
- 日志：`logs/server.log`；PID：`.run/uvicorn.pid`。
- 数据备份：`data/`（milvus_lite.db、*.db）。

## 5. 常见问题（FAQ）

| 现象 | 处理 |
|---|---|
| 登录失败 | 确认认证开启且账号/密码正确；错误多次会被记录 |
| 回答无来源/拒答 | 属防幻觉策略；补全/升级知识库后再问 |
| 上传提示超限 | 单文件须 ≤20MB |
| 服务未就绪 | 查看 `logs/server.log`，确认端口与 `.env` 配置 |
| 模型切换不生效 | 确认已配置真实 `RAG_LLM_API_KEY`，否则为 Mock 回退 |
