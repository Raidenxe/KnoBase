## 3. 功能测试用例（F）

### F-01 登录
- **前置**：服务就绪，认证开启。
- **输入**：`POST /api/v1/auth/login {username,password}`；（a）正确凭证（管理员由部署环境提供，口令以环境变量注入）；（b）错误密码。
- **预期**：（a）200，返回 `access_token` 与 user 信息，登录日志记录 IP/设备；（b）401。
- **验证**：断言状态码与响应字段；`GET /auth/profile/login-logs` 可见登录记录。
- **自动化**：tests/test_auth_rbac.py。

### F-02 RBAC 越权拦截
- **前置**：存在 member 与 viewer。
- **输入**：viewer 调 `POST /feedback`；member 调 `GET /auth/tenants`、`GET /auth/users`；无 token 调 `GET /documents`。
- **预期**：viewer 反馈 403；member 管理接口 403；无 token 401。
- **验证**：断言 HTTP 状态码；确认视角矩阵（功能说明 §5）成立。
- **自动化**：tests/test_auth_rbac.py、test_security_hardening.py。

### F-03 流式问答与引用
- **前置**：知识库已导入产品说明书；LLM 可用（或 Mock）。
- **输入**：`POST /chat/stream`，问题“默认管理员账号是什么”；另以 `doc_version` 限定范围。
- **预期**：SSE 依次收到 token/status/done；`done` 含 `answer`、`citations`（含 doc_id/doc_name/section_path/score）与 `suggestions`；引用编号与卡片一一对应。
- **验证**：断言 `citations` 非空且每篇引用可经 `GET /documents/browser` 定位到章节。
- **自动化**：tests/test_api.py、test_enhancements.py。

### F-04 会话增删改查/导出/分享
- **前置**：已登录 member。
- **输入**：新建会话→提问→重命名 PATCH→导出 `?format=markdown|text`→生成分享 POST→DELETE 会话。
- **预期**：各接口 2xx；导出含内容；收到 `{token}` 可经 `GET /shares/{token}` 匿名查看；删除后 404。
- **验证**：断言状态码与内容。
- **自动化**：tests/test_api.py。

### F-05 知识库上传/导入/删除/版本回滚
- **前置**：admin 登录。
- **输入**：`POST /documents/upload`（fixture MD）→ 列表可见 → 再上传覆盖（新版本）→ `GET /documents/{id}/versions` → `POST .../rollback` → `DELETE /documents/{id}`。
- **预期**：上传/覆盖后 `status=done`、`chunks>0`；versions 记录随覆盖增加；回滚后内容恢复并生成新修订；删除后检索不到。
- **验证**：断言各步骤状态码/字段；抽查 chunk 文本。
- **自动化**：tests/test_doc_mvp.py、test_version.py、test_kb_meta.py。

### F-06 反馈
- **输入**：`POST /feedback {conversation_id,message_id,rating,comment}`；admin 查 `GET /feedback/stats`。
- **预期**：member 提交成功；viewer 403；stats 汇总口径正确。
- **验证**：断言状态码与统计数值。

### F-07 控制台各 Tab
- **前置**：admin 登录打开 `/admin.html`。
- **输入**：切换 全量对话/反馈/链路/KB/性能/提示词/审计/资源/模型/参数/慢请求/用户/组/授权。
- **预期**：每个 Tab 均有数据渲染；提示词、模型、检索参数可保存即生效。
- **验证**：断言接口 2xx 且字段非空。

## 4. 性能测试用例（P）

| ID | 名称 | 输入/负载 | 预期(量化) | 验证方法 |
|---|---|---|---|---|
| P-01 | 检索响应 | 单问检索，计时 | 检索 < 500ms（P99） | `done` 事件 `metrics.retrieval_ms`；`/metrics/endpoints` |
| P-02 | 端到端问答 | 流式问答总耗时 | 端到端 < 3s（真实 LLM 下）；首字 < 1.5s | 计时 `metrics.total_ms`/首 token 延迟 |
| P-03 | 向量化吞吐 | 上传 20MB 文档 | 可后台进行，不阻塞问答；进度可见 | `/tasks/{id}` 进度 |
| P-04 | 并发 | 20 并发问答（4 组） | 无 5xx，吞吐 ≥ 阈值，P99 平稳 | locust/ab 脚本 + `P99` 断言 |

> 基准说明：当前环境为 Mock LLM，P-02/P-04 的绝对值需真实模型口径；检索相关（P-01/P-03）可在 Mock 下断言。

## 5. 边界测试用例（B）

### B-01 输入边界
- 空串、纯空白、1 个字符、超长（>2000 字）、纯标点/表情。
- **预期**：空/空白提示无效或正常拒答（不 5xx）；超长正常截断处理；重复提交被流式锁拦截（`streaming` 状态）。
- **验证**：断言 2xx 或 4xx，无 500。

### B-02 上传边界
- 0 字节文件；恰 20MB；超 20MB 单文件；不支持格式 `.exe`。
- **预期**：0 字节报格式/空内容错误；≤20MB 成功；>20MB 413/400；非法格式 400。
- **验证**：断言状态码与错误消息。

### B-03 参数边界
- `top-k` 取 1/12/大值；版本号列表边界；`ttl_seconds` 下界 60/上界 604800。
- **预期**：参数越界被 pydantic 校验（422），不 5xx。
- **验证**：断言 422/聚合不越界。

### B-04 多租户/分类授权边界
- 分类空文档；`access_scope=private` 文档对非 admin 不可见（列表），直接读取 `/content`/`/detail` 应被拒（当前为待修复缺陷，见 Q 备注）。
- **预期**：列表过滤正确；未授权文档访问应按授权拒绝。
- **验证**：断言可见性矩阵；对缺陷用例先标记 XFail/记录。

## 6. 异常测试用例（E）

### E-01 认证异常
- 无 Token、伪造 Token、过期 Token、停用账号登录。
- **预期**：分别 401；过期 401；停用拒绝。
- **验证**：断言状态码；`decode_token` 幂等。

### E-02 组件降级
- 置 `LLM_PROVIDER=mock`（无 Key）时问答走抽取式/拒答；Milvus URI 不正确时健康检查降级并显示原因。
- **预期**：不 5xx，返回可读错误或降级结果；`/health` 中组件状态清晰。
- **验证**：断言 2xx 与 `components` 字段。

### E-03 非法文件
- 上传损坏 PDF / 非 UTF8 TXT。
- **预期**：解析失败→文档 record `status=failed` + `error`；检索不受影响。
- **验证**：查询 `/documents` 状态。

### E-04 服务稳定性
- 重复 `./start.sh` 拦截；`./stop.sh` 优雅关闭、超时强杀；异常退出后 milvus-lite 锁冲突可自愈（重试 4 次）。
- **预期**：重复启动被 PID/端口拦截；停止兜底清理端口孤儿进程。
- **验证**：脚本退出码与日志。

## 7. RAG 回答质量评估用例（Q）

量化口径见 [模型参数精校报告.md](模型参数精校报告.md)「评估指标定义」。这些用例既是“可评估”回归项，也由 `scripts/eval.py` / `scripts/tune_retrieval.py` 落地。

| ID | 名称 | 输入条件 | 量化指标 | 目标阈值（预设） | 验证方法 |
|---|---|---|---|---|---|
| Q-01 | 准确性（事实一致性） | 金标问题，对照源章节 | 答案关键要素与来源一致率 | ≥95% | 人工/LLM 判定一致性 + coverage 校验 |
| Q-02 | 检索相关性 | eval 数据集（question→gold doc） | Hits@1/3/5、MRR@5 | Hits@1≥0.7, MRR@5≥0.8 | `registry.aggregate_retrieval_metrics` |
| Q-03 | 完整性 | 要求“步骤/配置”类问题 | 关键要素召回度、引用覆盖 | 引用含全部关键源 ≥0.9 | 输出要素比对 |
| Q-04 | 防幻觉/拒答 | 无知识支撑的问题 | 拒答率、幻觉率 | 拒答响应正确；幻觉 <5% | 对结果标注幻觉判定 |

> 说明：真实数值依赖真实 LLM；当前 Mock 环境以检索侧 Q-02 为主通道做参数精校，生成侧 Q-01/Q-03/Q-04 标记为“待真实模型联验”。
