# KnoBase RAG 智能助手 使用说明

本文档用于 KnoBase RAG 智能助手的功能测试，涵盖平台核心能力、检索范围与使用方法。

## 一、平台简介

KnoBase RAG 智能助手是一款基于企业知识库的检索增强生成系统。它支持从多种文档格式（PDF、Word、TXT、Markdown）导入知识，并通过向量检索与关键词检索的混合方式召回相关片段，最终生成带来源引用的回答。

系统名称来源于 "Knowledge Base"（知识库）的缩写。企业用户可将产品手册、操作规范、FAQ 等资料导入知识库，随后用自然语言提问，系统会依据知识原文回答，并为每个事实性结论标注引用来源 [1]、[2] 等编号。

## 二、核心功能

### 1. 知识库管理

知识库支持单文件上传、批量上传、网页抓取导入以及目录扫描。管理员可以将知识文档按分类组织，并为每个文档设置可见权限（租户可见或私有）。

### 2. 检索增强问答

当用户提出问题时，系统会执行混合检索：先通过语义嵌入向量召回相似片段，再结合 BM25 关键词检索，最后经 RRF 融合与重排，选出最相关的若干知识片段作为回答依据。回答会严格依据检索到的原文，超出去重后的知识范围时会明确拒答。

### 3. 来源溯源

每条回答在其事实性陈述后紧跟来源编号，点击编号即可跳转到知识库中的原始章节，方便核对与追溯。该机制可有效降低大模型幻觉风险。

### 4. 多轮对话

系统支持基于会话的多轮追问。用户在已开启的会话中继续提问时，上下文会被带入，回答更贴合前文意图。每个会话都可导出、分享或归档。

## 三、快速开始

### 1. 登录系统

访问系统登录页，输入管理员分配的账号密码。首次使用建议修改初始密码。

### 2. 导入知识

在"知识库管理"页点击"上传文档"，选择 Markdown、TXT、PDF 或 Word 文件。系统会自动解析标题结构、切片并向量化。上传完成后可在知识库浏览器的目录树中按章节浏览。

### 3. 开始提问

进入聊天页，在输入框输入问题，例如"KnoBase 的检索增强问答是如何实现的？"，系统会给出带引用标注的回答。

## 四、运维与排障

### 1. 系统健康检查

管理员可访问健康检查接口确认各组件状态：向量数据库（Milvus）、嵌入模型、大模型服务均在线时，系统处于健康状态。

### 2. 常见问题

- 问：检索没有命中怎么办？
- 答：请确认相关文档已成功导入并显示"完成"状态；可尝试使用更贴近原文的关键词，或缩小提问范围。

## 五、安全与权限

系统基于角色控制访问：管理员拥有全部权限，成员可读写知识库并参与问答，只读访客仅可检索与提问。私有文档仅对管理员与授权成员可见，普通用户无法在搜索结果中看到私有内容。

## 六、版本信息

当前系统版本号为 0.1.0。部署方式支持 Docker Compose，默认监听 8000 端口。默认租户为 "default"。
